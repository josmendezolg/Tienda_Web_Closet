# 👕 Tienda Web Closet

Un proyecto frontend de e-commerce que simula una tienda en línea. El objetivo principal de este desarrollo es la práctica de peticiones asíncronas y consumo de datos externos integrando **FakeStoreAPI**.

## 🚀 Tecnologías y Herramientas
* **JavaScript:** Lógica principal para realizar peticiones a la API y manipular el DOM (representa el 53.8% del código).
* **HTML5:** Estructura semántica de la aplicación.
* **CSS3:** Estilos visuales y diseño de la interfaz.
* **FakeStoreAPI:** API REST gratuita utilizada para obtener los datos de prueba de los productos (ropa, precios, descripciones e imágenes).
